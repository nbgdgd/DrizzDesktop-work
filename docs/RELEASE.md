## P2 - проверить на чистой Windows 10 и 11 перед релизом

- Установка, первый запуск (экран приветствия), автозапуск, удаление. Данные в `%LOCALAPPDATA%\DrizzDesktop` остаются после удаления - это нормально, но надо написать об этом в README.
- Машина без WebView2 и без интернета: NSIS по умолчанию скачивает загрузчик WebView2. Для офлайн-установки нужен `webviewInstallMode: embedBootstrapper`.
- Наушники: проводные, Bluetooth, USB-гарнитура, FxSound/Voicemeeter. Баланс на разных драйверах: на моно-выходе его нет, ошибка должна только попадать в журнал.
- Полноэкранные игры с античитом: питомец прячется, но хуки ввода остаются. Проверить 2-3 популярные игры.
- 4K при 150-200 %, два монитора с разным масштабом, сон и пробуждение, блокировка экрана.
- Нагрузка: 8 часов работы, процессор в покое меньше 1 %, память без роста (Диспетчер задач).
- Смена языка в панели: трей, реплики, облачка.
- Погода: поиск «Казань», «London», «Германия»; дождь - облачко и зонтик.

## Проверка без рук

`node tools/unattended-probe.cjs` на Windows после `npm run package` (или `--exe путь`). Около пяти минут не трогать мышь и клавиатуру. Отдельный профиль в `tools/qa-unattended-*`, твои настройки не меняются, громкость возвращается. Для проверки баланса включи музыку или видео. Проверяет:

- частоту кадров (должно быть 26+);
- защиту ушей после сна: процесс замораживается на 12 с, как при закрытой крышке, после этого громкость должна стать безопасной и питомец должен сказать об этом;
- баланс в микшере: программа сдвигается, сам выход нет;
- перетаскивание настоящей мышью на другой монитор (если мониторов два и больше);
- сброс баланса, который делает деинсталлятор.

Переподключение наушников так не проверить: это вручную, выдернуть и вставить при включённой защите. Там же: с играющей музыкой снять Bluetooth-наушники - плеер должен встать на паузу; заряд на вкладке «Уши» должен совпасть с Параметрами Windows; сохранить профиль, переключиться на колонки и обратно - настройки профиля должны вернуться.
